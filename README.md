# Prompt Empire Nexus: Fractal AR Forage Odyssey

**Seed:** AI Prompt Marketplace with Reverse Seed-to-Roots Engineering + Unity AR Game Prototype.

## Quick Ignite
- Backend: `cd backend && node server.js` (Port 3000)
- Frontend: `cd frontend && yarn start` (Port 3001)
- Unity: Open `unity-ar-forage/` in Editor; Build AR APK/IPA.
- Fractal Sim: `node tools/seed-fractal.js "Your Seed Here" --steps=6 --reverse`
